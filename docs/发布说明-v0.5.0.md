# v0.5.0 发布说明（第二周交付）

> 发布日期：2026-11-29　｜　基线：`main@5436395` 起　｜　验证环境：Chrome / Edge（Windows）
>
> 本周目标：把「能跑」推进到「可完整演示的 v0.5.0」。

## 1. 本周新增

### 引擎 / 集成（林子涵）

- `createRenderPipeline()` 接管主场景渲染：后处理（Bloom / 暗角 / ACES）负责每帧输出；
- 移除旧 `atmosphere-legacy` 光源与玩家灯笼，统一为月光 + 灯笼 SpotLight + 火盆点光三光源，
  消除双份光源 / 双份阴影；
- 画质档从「只改 pixelRatio」升级为参数 + 特性组合：high 全开；medium 关体积光；
  low 关体积光 / Bloom 并切 Blinn-Phong（保留灯笼与阴影）；
- 新增 `window.changming.getPipelineDiagnostics()` 与 URL 调试参数
  `?quality=low&water=1&rain=1&bloom=0`；
- CI 增加渲染配置契约测试与迷宫同 seed 测试。

### 渲染 / 特效（黄勇杰）

- 真实迷宫场景调参（Bloom / 体积光密度 / 雨亮度）；
- 新增 `rain` 特性：相机局部雨丝 + 地面涟漪 shader，默认关闭、可 URL / 诊断开启；
- 主场景 4 张技术对比图 + 1 张雨/涟漪图，真 GPU 性能记录（Chrome 292.3 / Edge 278.8 FPS）。

### 迷宫 / 世界（王圣杰）

- 规格定稿为 **15×15**：4m 格、4.5m 墙高、0.62m 墙厚，文档口径全部统一；
- `buildMazeMesh(options)` 契约补进接口文档（输入 / 输出 / 材质分组 / 合批规则）；
- 世界合批：远景船、火盆火焰、灯塔窗、门箍、中庭装饰实例化；静态合批不再按阴影标记拆批；
- 首帧 draw calls 259 → 172，稳定帧高画质 173 → 125、低画质 109 → 72；
- 新增同 seed 一致性测试（`npm run test:maze`，覆盖 100 个 seed 可达性与三火种分布）。

### 玩法 / UI（张洋）

- 标题 / 开始界面：`title → playing`，开始按钮解锁音频，三种开始方式；
- `R` 检查点 / 落水重生：每 1.2s 采样安全点，卡墙或掉出场景自动重生；
- 小地图 + 迷雾：Canvas 2D，四区域配色、玩家朝向、火种 6m 内显示、大门常显，窄屏自适应；
- HUD 打磨：修掉四个未定义 CSS 变量，按 `body[data-phase]` 控制显隐，补 `R` 操作提示；
- 2 分钟试玩脚本与自测记录。

### 材质 / 音频 / 测试 / 文档（吴嘉晔）

- AudioManager 增加纯代码海浪 / 风声环境音与音量控制 API；
- 四区域材质补充法线细节生成器；
- 资产许可登记更新为「100% 程序化、无外部素材」；
- 自动截取四区域与画质对比测试图。
