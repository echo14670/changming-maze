## 2. buildMazeMesh 契约

已在 `docs/接口文档.md` 增加 `5.2A 迷宫网格 buildMazeMesh(options)`，记录：

- 输入：`maze`、`materials`、可选 `seed`；

- 动态对象排除规则；
- 同 seed 可复现约束。

## 3. Draw call 合批

本轮优化：

- 11 条远景船合并为 1 个动态 `InstancedMesh`；
- 7 处火盆火焰合并为 1 个动态实例批次；
- 灯塔四扇窗共用材质并进入静态合批；
- 双门金属箍从 8 个 Mesh 降为 2 个实例批次；
- 墙帽、芦苇、岛缘岩不再重复进入阴影 Pass；
- 中庭台阶、边缘、罗盘金线、扶手改为实例化，并在 `StoneMaze` 内部按材质烘焙合批；
- 世界级静态合批不再按 `castShadow/receiveShadow` 拆散同材质批次，改为合并后取并集。

默认 seed `20261205`、1440×900、Chromium headless 对比：

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| B 世界网格节点 | 95 | 53 |
| 实例批次 | 19 | 23 |
| 静态合批输入 → 输出 | 未单独统计 | 215 → 22 |
| 入口首帧 draw calls | 259 | 172 |
| 稳定帧高画质 draw calls | 173 | 125 |
| 稳定帧低画质 draw calls | 109 | 72 |
| 场景三角形 | 75,859 | 75,871 |

`buildMazeMesh()` 单独输出 22 个绘制对象，其中 18 个实例批次，满足迷宫自身 ≤40 的目标。

复测：

```bash
npm run build
npm run measure:world
```
