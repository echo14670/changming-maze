# 第三周任务（11.30–12.06）

> 项目：《长明：雾海迷宫》　｜　起点：`v0.5.0`（第二周交付）
> 本周目标：从「可完整演示」推进到「**可答辩交付的 v1.0**」——结局镜头闭环、声音与画面收口、答辩材料齐备。
>
> 本文按「向子 agent 交付任务」的方式写给每位成员：每个任务都写清**目标、交付物、验收标准、边界**。
> 不排到具体日期，由各人按依赖顺序推进；集成窗口由林子涵统一安排，合入节奏以 PR 为单位。

---

## 0. 本周全队分工原则

1. **一人一模块，接口先行**：跨模块只走 `docs/接口文档.md` 的契约；改接口必须先改文档再改代码。
2. **每个任务 = 一个 PR**：标题 `feat(scope): 简述`，描述包含「目标 / 改动 / 验收方式 / 截图或数据」。
3. **合并门槛**：`npm run build`、`test:config`、`test:maze`、`test:game`、`npm test`（Chrome + Edge）全过，控制台 0 error。
4. **不引入外部素材**：纹理、音频继续程序化生成；确需外部资源必须 CC0/CC BY 并登记 `assets/LICENSES.md`。
5. **阻塞要当天说**：PR 描述里写清依赖与阻塞，群里同步；不要憋到周末。
