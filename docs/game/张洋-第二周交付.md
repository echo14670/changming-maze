## 2. 标题 / 开始界面（`src/ui/title-screen.js`）

- 覆盖全屏的标题遮罩：课程信息、品牌字、剧情引子、开始按钮、完整按键表、Pointer Lock 提示；
- `start()` 流程严格按接口文档 §5.8：**解锁音频 → `state.phase = 'playing'` → HUD 淡入**，
  并发 `game:start` 事件；
- 三种开始方式：点击任意处 / 开始按钮 / `Enter` / `Space`；
- 构造时锁定输入与相机（`input.setEnabled(false)`、`cameraRig.setEnabled(false)`），
  `main.js` 原有的「临时强制 `playing`」占位已删除；
- 遮罩 `pointer-events: none`，点击穿透到 canvas，由文档级监听触发开始——
  保证回归脚本仍能点到 canvas（Playwright 的 actionability 检查会拒绝被遮罩拦截的点击）。

## 3. `R` 检查点 / 落水重生（`src/game/respawn.js`）

- 每 1.2s 采样一次可行走位置为安全点，并同步 `state.checkpoint`（诊断可读）；
- `R` 手动回安全点，HUD 提示「已回到检查点」；
- 位置被墙体夹住或掉出场景（`y < -1.5` / 坐标非法）持续 0.45s 自动重生，
  提示「已回到安全位置」，并发 `player:respawn`（`{reason, count}`）；
- 只调 `world.isWalkable` / `cameraRig` 公开方法，不碰碰撞内部实现；
- 调试：`window.__changming.respawn.getSafePosition()` / `getRespawnCount()`。

## 4. 小地图 + 迷雾（`src/ui/minimap.js`）

- Canvas 2D，挂在 `#hud` 内左下角，不进入 three.js 渲染循环，**零额外 draw call**；
- 15×15 格，当前格 + 相邻 8 格揭示迷雾；已探索格按四区域色绘制地面与墙体；
- 玩家位置/朝向箭头、入口常显、灯塔大门常显（金色标记）；
- 火种按接口约定 **6m 内才显示图标**，已拾取不再绘制；
- 绘制节流约 8fps；`getVisitedCount()` 供诊断统计；
- 窄屏（≤720px）缩小为 112px，不与操作提示重叠。

## 5. HUD 打磨

- 修复 `hud.css` 中 `--hud-ink / --hud-ember / --hud-muted / --hud-line` 四个变量
  未定义的问题（此前 `var()` 全部落空，文字色依赖浏览器兜底）；
- HUD 可见性改为按 `body[data-phase]` 控制：标题期隐藏、playing 淡入、ending 淡出（1.2s）；
- `createHud` 新增 `show()` / `hide()`（对齐接口 §5.8 的 `showHUD/hideHUD`），
  原 `setCount / setInteraction / setGuide / showToast / setRegion` 签名不变；
- 底部操作提示补 `R` 回检查点；`index.html` 与 hud.css 的样式变量统一。

## 6. 结局入口预留

- `main.js` 监听 `ending:start`：锁定输入与相机、`body[data-phase="ending"]`、HUD 淡出；
- 主循环只在 `phase === 'playing'` 时更新玩家/交互/重生，ending 期间不再响应 WASD；
- 正式镜头（12–15s 五点路径）第三周在 `src/game/` 内补 `createEnding`，
  大门交互的 `world.setDoorOpen(1)` 行为保持不变、不提前接入镜头。

## 7. 接口变化

事件表新增两行（`docs/接口文档.md` 已同步，v0.4.1 → v0.4.2）：

| 事件 | payload | 生产者 | 消费者 |
| --- | --- | --- | --- |
| `game:start` | `{}` | TitleScreen | Audio / 任意观察者 |
| `player:respawn` | `{ reason: 'manual'\|'auto', count: number }` | Respawn | UI / Audio |

影响：无破坏性变更；吴嘉晔的 Audio 可按需订阅 `player:respawn` 补重生音效，
不订阅也不影响现有流程。`window.changming` 诊断 API 未变。
