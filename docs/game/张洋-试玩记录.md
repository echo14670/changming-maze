# 张洋 · 2 分钟试玩脚本与记录

> 用途：答辩演示 / 回归自测的固定流程。全程约 2 分钟，覆盖本周全部玩法与 UI 功能。
> 环境：`file://` 双击 `index.html`（Chrome / Edge），1440×900，默认 seed `20261205`。

## 1. 试玩脚本（按时间轴）

| 时间 | 操作 | 预期表现 |
| --- | --- | --- |
| 0:00–0:12 | 打开 `index.html` | 标题界面淡入：品牌字「长明」、副标题 THE LONG LIGHT、剧情引子、开始按钮、按键表 |
| 0:12–0:15 | 点击「提灯入阵」或按 Enter | 遮罩淡出，HUD 淡入，左上角品牌、顶部区域名、右上火种 0/3、左下小地图 |
| 0:15–0:18 | 点击画面 | Pointer Lock 生效（鼠标环视）；若浏览器拒绝则按住左键拖动环视 |
| 0:18–0:45 | `W` 沿石道进入迷宫，`Shift` 偶尔快走 | 移动流畅、贴墙滑动不穿模；小地图沿路揭示迷雾，玩家箭头随转向旋转 |
| 0:45–0:55 | 走到水院火种约 3m 内 | 火种高亮放大，准星变亮，底部浮出「E 拾取水院火种 · 距离 x.x m」，小地图 6m 内出现火点 |
| 0:55–1:00 | 按 `E` | 火种上升缩小消散，HUD 计数变 1/3，dots 第一格点亮，顶部 toast 提示 |
| 1:00–1:10 | 按 `R` | 提示「已回到检查点」，位置回退到最近安全点（验证检查点可用） |
| 1:10–1:30 | 继续找烬厅、外庭两枚火种 | 计数 2/3 → 3/3；小地图上未拾取火种依次消失 |
| 1:30–1:40 | 回到中央中庭，靠近灯塔大门 | 提示「将火种送入主灯 · 长明之门已经准备好」，准星高亮 |
| 1:40–1:50 | 按 `E` | 大门开启、主灯点亮、音效触发；屏幕提示「火种已经送入主灯」 |
| 1:50–2:00 | 按 `Esc` 退出 Pointer Lock，回看 HUD | 火种 3/3 满格、区域名切换正确、小地图完整显示探索路径与大门口标记 |

> 结局镜头（12–15s 拉远）第三周接入，本版 `E` 开门后停在「长明之光正在穿透雾海」提示，
> 用 `window.changming.triggerEnding()` 只切状态、不播镜头。

## 3. 已知问题

1. 无正式 `createPlayer`，当前第一人称仍由引擎 `cameraRig` 承担（头部微晃、落水音效缺）；
2. Pointer Lock 被浏览器拒绝时只能拖动环视，无自动提示横幅；
3. 小地图不显示未探索区域的任何轮廓（有意设计，避免提前剧透迷宫结构）；
4. 火种 6m 标记在两层墙体后方也会显示（按接口约定只做距离判定，不做视线判定）。
