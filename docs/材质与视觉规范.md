# 《长明：雾海迷宫》材质与视觉规范

## 1. UI 色板 (Color Palette)
全项目统一使用以下 CSS 变量（已在 `src/ui/hud.css` 中声明）：
- **夜蓝 (Night)**：`#0b1a24`（主背景、深海、UI 底色）
- **雾灰 (Fog)**：`#9fb0b5`（环境雾效、次要文本）
- **灯火橙 (Ember)**：`#ffb45c`（火种、主光源、高亮交互、强调文字）
- **暗礁 (Reef)**：`#2a363b`（石墙基础色）

## 2. 纹理资产规范
- **尺寸与精度**：统一采用 **1K (1024 x 1024)** 分辨率，确保无头浏览器测试时的显存占用可控。
- **格式**：尽量使用程序化生成（Canvas API），若需要外部资产请导出为 WebP（质量 80%）。
- **PBR 法线**：所有基础纹理（石、苔、砖、木）需要配套生成 Height/Bump Map 并转换为 Normal Map。

## 3. 墙面材质清单
| 材质名称 | 视觉特征 | 基础色 | 噪点/纹理特征 |
| :--- | :--- | :--- | :--- |
| **环塔石墙 (Stone)** | 粗糙、大块不规则石砖 | `#2a363b` | 低频 FBM 噪声，砖缝深黑 |
| **潮汐青苔 (Moss)** | 贴地生长，湿润感 | `#3a4a3a` | 高频斑块，边缘羽化 |
| **红砖内墙 (Brick)** | 规则排列，符合迷宫 | `#4a2e2e` | 典型交错砖块网格 |
| **陈年木门 (Wood)** | 纵向木纹，有节疤 | `#3b2a1e` | 正弦波扭曲的纵向渐变 |

## 4. UI 视觉规范
- 中文字体：`PingFang SC`, `Microsoft YaHei`, sans-serif。
- 标题字体：Georgia, "Songti SC", serif（强调长明灯的神圣感）。
- 对比度：所有文字必须在夜蓝底色上保持 4.5:1 以上的对比度（灯火橙文字非常合适）。
