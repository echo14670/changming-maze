## 1. 本周总目标与验收

**一句话目标**：在一个 15×15 的程序化迷宫里，用第一人称走一圈；灯笼有动态阴影；能捡起火种并看到 HUD 计数；`file://` 双击 `index.html` 可运行，控制台零 error。

周日 11.22 的验收门禁：

- [ ] `npm run build` 通过，`dist/bundle.js` 生成；
- [ ] `index.html` 双击可运行（Chrome / Edge），无 console error；
- [ ] 同一个 seed 两次生成的迷宫完全一致；
- [ ] 能走到 3 枚火种的位置并拾取，HUD 显示 `0/3 → 1/3 → 2/3 → 3/3`；
- [ ] 灯笼聚光有阴影，开关阴影能看到差异；
- [ ] `window.changming.getState()` / `getDiagnostics()` 可用；
- [ ] 1440×900 下至少 30fps（本周先不追 60）。

## 9. Definition of Done（每个 PR 都要满足）

- [ ] `npm run build` 通过；
- [ ] `file://` 双击 `index.html` 无 console error；
- [ ] 只改自己模块，接口变更已同步 `docs/接口文档.md`；
- [ ] 新资产已登记 `assets/LICENSES.md`；
- [ ] PR 描述写清“做了什么 / 怎么测 / 截图或录屏”；
- [ ] 没有提交 `node_modules/`、`dist/`、个人截图、概念图。

## 10. 提交与合并

- 每人从 `main` 开自己的 `feat/...` 分支，**周日 18:00 前**发 PR 到 `main`；
- PR 标题：`[模块] 一句话`，例如 `[maze] DFS 迷宫生成与碰撞`；
- 至少 1 个 approve；接口/渲染管线改动由林子涵加审；
- 合并后删除功能分支；`main` 通过后打 `v0.1.0`；
- 周报只写三行：本周目标、完成情况、项目进度（30%）。
