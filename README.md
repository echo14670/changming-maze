# 长明：雾海迷宫

> 计算机图形学综合实验四 · 第一人称 3D 迷宫 · WebGL2 / three.js

风暴夜，灯塔熄灭，三枚火种散落在环塔石阵。玩家提灯进入迷宫，找回火种，回到中央灯塔大门，把火种送入主灯；光束穿透雾海后，镜头自动脱离第一人称、拉远展示灯塔、石阵、海岛与大海。

## 项目状态

当前 `dev` 已接入可运行的 B 场景与火种拾取闭环：

- three.js + esbuild IIFE，`npm run build` 产出 `dist/bundle.js`；
- WebGL2 渲染循环、resize/DPR、性能统计；
- 输入抽象（Pointer Lock + 拖动回退）、调试相机；
- 15×15 DFS 石阵、四区域、灯塔、礁岛、外海与墙体碰撞；
- 三枚带发光核心、光晕、旋转环和火星的火种；
- 宽松距离/视线判定、自动高亮、`E` 提示、拾取动画和 `0/3 → 3/3` HUD；
- 集齐火种后灯塔大门提示与开门/主灯接口；
- `window.changming` 诊断接口；
- Playwright 冒烟测试，自动验证三枚火种均可拾取。

玩家正式控制器、结局镜头、小地图、正式渲染特效和音频仍在各自模块开发中。

## 本地开发

```bash
npm install
npm run build     # esbuild 打包到 dist/bundle.js
npm run watch     # 开发时监听
npm test          # Playwright 冒烟测试（先 build）
```

构建后双击 `index.html` 即可运行（`file://`，不需要本地服务器）。

当前已接入迷宫世界、带碰撞的第一人称预览移动、火种拾取与 HUD；结局镜头和小地图仍待接入。

## 操作

| 输入 | 功能 |
| --- | --- |
| `W A S D` | 移动 |
| 鼠标 | 点击场景后 Pointer Lock 环视；失败时按住拖动 |
| `Shift` | 快走 |
| `E` | 靠近火种后拾取；集齐后操作中央灯塔大门 |

火种拾取采用宽松判定：约 2 m 内靠近即可聚焦，2–4.5 m 内只需把火种放进较宽的视线范围。屏幕会自动显示目标距离和 `E` 提示。
